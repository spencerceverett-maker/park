Welcome to your Remotion project!

## Commands

**Install Dependencies**

```console
npm i --loglevel=error
```

**Start Preview**

```console
npm run dev
```

**Render video**

```console
npx remotion render
```

**Upgrade Remotion**

```console
npx remotion upgrade
```

## Park demo

`src/ParkDemo.tsx` is the README demo (1920×1080, 60 fps). Render from this folder:

```bash
npx remotion render ParkDemo ../docs/demo.mp4 --codec=h264 --crf=22
npx remotion render ParkDemo ../docs/demo.gif --codec=gif --frames=222-512 --every-nth-frame=3 --scale=0.42
```
